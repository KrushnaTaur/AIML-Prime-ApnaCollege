# Data Handling

This module contains my complete learning and hands-on practice related to **data handling and preparation**
for AI/ML as part of the **Apna College PRIME AI/ML course**.

The focus of this module is on working with real-world data — from loading and cleaning data
to collecting, querying, and visualizing it.

---

## 📚 Topics Covered

### 🔹 NumPy
- Array creation and properties
- Indexing, slicing, and reshaping
- Multi-dimensional arrays
- Vectorization and broadcasting
- Mathematical and statistical operations

### 🔹 Pandas
- Series and DataFrames
- Loading data from CSV and JSON
- Indexing, filtering, and querying
- Data cleaning (missing values, duplicates, data types, strings)
- Data transformation and aggregation
- Merge, join, concat, melt, and pivot operations
- Basic visualization using Pandas

### 🔹 SQL
- Database and table creation
- CRUD operations
- Constraints, primary and foreign keys
- Joins and subqueries
- Aggregations and grouping
- Transactions, indexes, views, and procedures

### 🔹 Web Scraping
- Working with APIs
- HTML basics for scraping
- Web scraping using `requests`
- Data extraction using `BeautifulSoup`
- Storing collected data (CSV / JSON)

### 🔹 Data Visualization
- Data visualization concepts
- Plotting with Matplotlib
- Line, bar, scatter, histogram, box, and pie charts
- Subplots, styling, and saving plots
- Visualization using Seaborn
- Heatmaps and visualization best practices
